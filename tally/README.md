# Tally

A wallet app with four seeded UI bugs, the demo for WidgetFix. It is the Flutter port of the SwiftUI Tally in the original FixKit, and it depends on `packages/widget_fix` by path.

```bash
../scripts/reset-demo.sh       # puts the bugs back and runs the app under flutter run
claude --plugin-dir ../mod     # in another terminal, in this folder
```

The README at the root of the repository lists the bugs and the comments that fix them.
